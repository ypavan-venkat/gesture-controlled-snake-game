🐍 AI-Powered Gesture Controlled Snake Game
📌 Overview

This project implements a real-time Snake game controlled using hand gestures via webcam.

🧠 Features

Real-time hand tracking using MediaPipe

Custom finger-count gesture recognition

Integrated OpenCV + Pygame pipeline

Collision detection & game state management

Smooth gesture-based control

🛠 Tech Stack

Python

OpenCV

MediaPipe

Pygame

🎮 Gesture Controls
Fingers	Direction
1	Up
2	Down
3	Right
4	Left
